About DNSTools

DNSTools is a privacy-focused, client-side web toolkit for DNS lookups, WHOIS/RDAP domain registration queries, and email security analysis. All queries run directly from your browser, nothing is logged by this application.

Providers:

  • • dns.google/resolve (DNS, primary)
  • • cloudflare-dns.com/dns-query (DNS, fallback)
  • • dns.quad9.net/dns-query (DNS, fallback)
  • • data.iana.org/rdap (WHOIS/RDAP bootstrap)

Privacy First Architecture

  • 100% Client-Side: All logic runs locally in your browser.
  • No Backend Tracking: We do not store or see your queries.
  • Secure Transport: Uses HTTPS for all DNS requests.
